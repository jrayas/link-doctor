# Link Doctor

An Obsidian plugin that finds, explains and fixes broken links, with a preview and undo for every fix.

Status: under construction (see `docs/plan.md`). Full usage and limitations will be added in the release phase.

## Development

```
npm install
npm run dev       # watch build
npm run verify    # lint, typecheck, test, build, bundle check
```

Requires Node 22 or later. All scripts are Node-based and run on macOS, Windows and Linux.
